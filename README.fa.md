## 🧭 ایده کلی

```
ابزار چت (یک Base URL + یک کلید) ──▶ ورکر Cloudflare (آدرس ثابت) ──▶ استودیو مدل‌اسکوپ (9Router)
```

> **ورکر برای چیه؟** گیت‌وی مدل‌اسکوپ هدر `Authorization` را برای توکن خودش برمی‌دارد؛
> پس کلاینت‌های تک‌فیلدی نمی‌توانند مستقیم وصل شوند. ورکر هدرهای گیت‌وی را خودش اضافه می‌کند.

## 🛠️ راه‌اندازی قدم‌به‌قدم (فقط با مرورگر)

### قدم ۱ — ساخت استودیو
- در `modelscope.ai` استودیوی نوع **Docker** با سخت‌افزار رایگان بسازید.
- همین ریپو را به گیت استودیو (شاخه `master`) پوش و **Deploy** کنید (بیلد اول ۳-۵ دقیقه).

### قدم ۲ — Secrets استودیو (فقط از صفحه استودیو، هرگز داخل کد!)
| کلید | مقدار |
|------|--------|
| `JWT_SECRET` | یک رشته رندوم طولانی |
| `INITIAL_PASSWORD` | پسورد دلخواه داشبورد |
| `REQUIRE_API_KEY` | `false` |

> تغییر سکرت `INITIAL_PASSWORD` پسورد ذخیره‌شده در دیتابیس را عوض نمی‌کند؛
> پسورد را از داخل داشبورد عوض کنید یا دیتا را پاک + redeploy کنید.

### قدم ۳ — ساخت کلید 9router
- داشبورد → API Keys → ساخت کلید (`sk-...`). بعد از تست بچرخانیدش.

### قدم ۴ — روشن کردن تونل (آدرس موقت)
- داشبورد → Tunnel → **فقط یک‌بار** Enable (هر کلیک آدرس جدید می‌سازد).
- تست: `GET <tunnel>/api/health` باید `{"ok":true}` بدهد.

### قدم ۵ — اتصال برنامه بیرونی
- از طریق تونل: Base URL = `<tunnel>/v1` و API Key = `<کلید-9router>`
- ⚠️ هاست `ms.fun` به کلاینت مستقیم API نمی‌دهد (403) و هاست `api-inference` توکن مدل‌اسکوپ می‌خواهد؛
  پس کلاینت تک‌فیلدی حتماً باید از تونل یا ورکر استفاده کند.

### قدم ۶ — آدرس ثابت با ورکر خودتان (پیشنهادی)
۱. داشبورد Cloudflare → Workers & Pages → ساخت ورکر → paste کردن `workers/bridge-template.js` → Deploy.
۲. متغیر `TUNNEL_URL` (آدرس فعلی تونل) و سکرت `MS_TOKEN` (توکن مدل‌اسکوپ، فقط fallback) را ست کنید.
۳. در برنامه‌ها: Base URL = `https://<worker>.<subdomain>.workers.dev/v1` و API Key = کلید 9router.
۴. با تغییر تونل فقط `TUNNEL_URL` را آپدیت کنید.

### قدم ۷ — اضافه کردن کلیدهای پرووایدر
- داشبورد → Providers → همه کلیدها را اضافه کنید تا 9router موقع ریت‌لیمیت خودکار سوییچ کند.

## 🔒 امنیت
- هیچ توکن/پسورد واقعی در این ریپو نیست. مقادیر واقعی فقط در Secrets استودیو و Secrets ورکرند.
- کیپ‌الیو کم‌تکرار و انسانی طراحی شده ولی دور زدن sleep پلتفرم ممکن است خلاف ToS باشد — مسئولیت با شماست.
